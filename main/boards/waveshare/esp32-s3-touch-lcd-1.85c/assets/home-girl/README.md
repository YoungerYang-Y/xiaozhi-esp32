# HOME 小妹妹资源

选定 B 款日系卡通小女孩：棕色短发、珊瑚色发夹、粉色圆领衣服、黑色背景。
`source/` 保存内置 imagegen 生成的原始 PNG，`profile.json` 保存唤醒词和情绪映射。
不直接在设备上解码大原图；打包脚本按长边 160px 转换为小尺寸纹理。

## 生成与使用

在 ESP-IDF 6.1 环境、仓库根目录运行，Python 需安装现有构建依赖 Pillow、NumPy：

```sh
python scripts/build.py waveshare/esp32-s3-touch-lcd-1.85c \
  --config config.home.json --name esp32-s3-touch-lcd-1.85c-home
python scripts/build_home_girl_assets.py
```

独立输出为 `build/home-girl-assets.bin`，最大 8 MiB。脚本核对当前构建属于
ESP32-S3 HOME，保留 `generated_assets.bin` 中的字体、glyph 元数据与其他资源，
替换表情和语音模型。它不会更改 sdkconfig、vendor 模型、固件或 NVS。
部署时须显式选择该资源文件；常规构建及其 merged-binary 仍包含默认资源。
部署工具需按实际分区表写入，并核验应用、资源和设置后复位。

模型使用已安装 ESP-SR 的 `mn7_cn` 和 `fst`，仅注册 `ni hao xiao mei mei`
（你好小妹妹），阈值 0.2，识别窗口 3000ms。模型在现有 AFE 引擎中运行，
不用修改唤醒词音频上传或网络协议。词表激活与识别效果必须在设备上确认。

## 表情

21 个既有情绪名称映射到同一角色的 8 种基础表情。相近情绪共享资源，详见
`profile.json`。待机使用睁眼、闭眼、睁眼三帧 GIF，时长为 3800/120/180ms；
其余情绪为静态 PNG。它不是与语音同步的口型动画。

所有基础图片保持相同构图；GIF 共用调色板，限制帧尺寸并保留黑色背景。
动画和图片都放进固定媒体区，不改变屏幕布局。

## 原画提示词

使用内置 imagegen，参考用户选定的 B 款原图。基础编辑提示为：保持人物身份、
面部、棕色波波头和刘海、珊瑚色发夹、眼睛、正面头肩构图、日系线稿、黑色
方形背景；仅将浅绿圆领衣服改为柔和浅粉色，保持衣服轮廓与明暗。无文字、
界面、边框或新增物体。

后续表情均参考粉衣基础图，只改变眼眉口的表情，保留头部大小位置、发型、
衣服、轮廓、色彩及背景：

| 原图 | 表情提示 |
| --- | --- |
| neutral | 温和的闭嘴微笑、棕色眼睛正视 |
| blink | 双眼自然轻闭，微笑不变，单次眨眼帧 |
| happy | 开心的眼神和适度张嘴微笑 |
| sad | 柔和担忧眉、小幅嘴角下垂，无夸张眼泪 |
| thinking | 一侧眉微抬、目光略向上、闭嘴思考 |
| sleepy | 半闭困倦眼睛、小而放松的嘴，头保持直立 |
| surprised | 眼睛睁大、眉上抬、小圆口，无符号 |
| angry | 温和皱眉、小幅噘嘴，无愤怒特效 |
| winking | 单眼轻闭，另一眼睁开，友好微笑 |
