# 家用离线交互实施计划

逻辑基线：2.6.0。输入：[行为规格](spec.md)、[实现设计](design.md)、[已确认方案](proposal.md)。
目标为完整实现 AC01–AC24 的代码与主机验证；设备验收不等同于构建通过。本计划不记录执行状态。

| 任务 | 依赖 | 独占写入范围 |
| --- | --- | --- |

## T1 网络与恢复

新增后台服务单次配置/激活/无音频恢复探测及结果邮箱；失败有界返回，由应用退避重试。
Board抽象提供启停和配网；HOME 超时只结束前台等待，不强制配网。停止配网前屏蔽 Exit 自动重连。
探测临时协议生命周期封闭，不将其业务消息交给应用。覆盖 AC03–09、19、20。

## T2 本地识别与资源

先回归固定 action/epoch/取消，再扩展 MultiNet、AFE、AudioService；8秒由应用管理。
保证本地识别不启用语音上行，wake和command阶段互斥；补充完整词表及脚本验证。
建立资源更新前音频任务停用/引用释放能力，保留本地先加载、延后下载流程所需接口。
覆盖 AC11–18、23、24；编译音频相关host测试，默认无MultiNet诚实降级。

## T3 菜单与板级输入

Display可选菜单接口，LCD渲染菜单与命中区域；具体板卡长按回应用，触点优先菜单，普通双击背光保持。
T3同时实现Display::PrepareForAssetUpdate屏障：停止GIF/预览、对象及主题脱离旧映射并绑定内置字体；返回false禁止资源写入。T4在后台更新任务中先调用T2音频屏障、再调用T3显示屏障，两者成功才调用T2 Assets::Download；成功后Assets::Apply重绑显示，失败保留基础界面。以host适配器验证调用顺序和任一屏障失败无写入。
BOOT在菜单内单击选项、再次长按确认，双击仍暂停；长按/释放及菜单退出尾随输入不能开始聆听。
覆盖 AC10、13、14、21、22，基础字体在资源不可用时仍能操作菜单。

## T4 策略及应用整合

纯策略带可注入时钟的窗口、菜单、模式及重试；checked持久化手动离线。
新增离线待机/本地识别合法状态，所有变化经状态机；适配旧host harness并验证真实生产方法。
在线单击取消；后台实际建连捕获协议所有权及generation，取消不会重启收音。
在所有业务消息/音频/通知/工具入口拦截离线、取消及探测的旧事件。
资源加载独立于网络；更新后台执行，主任务只处理完成状态；释放失败不覆盖资源。
覆盖全部AC，CMake只为HOME加入专用源文件。

## T5 验证

运行主机全部测试和受影响文件 clang-format 检查；使用已安装 ESP-IDF release/v6.1、mise Python 3.12。
按 scripts/build.py 构建 1.85C HOME 与代表非HOME路径；打包家用资源，验证词表及分区大小。
独立审查代码、接口及验收证据，修复确认问题。保留编译/环境限制的实际证据，不虚报硬件通过。
更新板卡操作说明，不改变发布版本、不提交、不烧录。

## 决策边界

可自行选择私有实现、测试适配及相同模块内必要文件；保持用户确定的交互、固定词表、持久化和音频隔离。
网络或工具缺失先排查环境，不改行为绕过检查。所有外部写入、烧录与Git历史操作仍须单独授权。
