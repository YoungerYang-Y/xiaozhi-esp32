# 家用离线交互行为规格

基于现有 2.6.0 代码；不调整发布版本。范围与完整参数以 [已确认方案](proposal.md) 为准。

## Behavior：聆听与取消

- Given 在线待机，When 单击 BOOT，Then 开始一次云端聆听。
- Given 正在连接或聆听，When 再次单击，Then 取消本次请求，迟到结果不能恢复收音。
- Given 已暂停监听，When 单击或网络恢复，Then 保持暂停；双击才撤销暂停。

## Behavior：离线与恢复

- Given 保存了手动离线，When 重启，Then 不启动 Wi-Fi，保留本地操作。
- Given 允许联网但启动 15 秒仍不可用，When 前台预算到期，Then 本地能力可用，后台递增重试至最长间隔 300 秒。
- Given 服务恢复，When 无音频的控制握手通过，Then 在本地交互结束后恢复在线待机；媒体未知不阻止无探测协议恢复。
- Given 首次无配置，When 单击退出配网，Then 保存手动离线且不清除配置或绑定。

## Behavior：菜单

- Given 普通交互，When 长按 BOOT 3 秒，Then 取消当前交互并亮屏打开网络菜单，默认选择返回。
- Given 触控失效，When 单击循环选择、再次长按确认，Then 可恢复联网、配网及返回。
- Given 菜单打开，When 双击改变暂停选择并返回，Then 使用新的暂停选择，不恢复旧指令窗口。

## Behavior：本地指令

- Given 离线待机，When 唤醒或单击，Then 开启最多 8 秒窗口，一次执行一条已确认固定指令。
- Given 音量 95，When 音量大一点，Then 保存 100；Given 息屏，When 屏幕亮一点，Then 只改变保存亮度。
- Given 未识别、超时或取消，When 窗口关闭，Then 不执行动作；离线音频不上传或补传。
- Given 模型缺失，When 尝试本地识别，Then 显示不可用，并保留物理恢复入口。

## Behavior：资源

- Given 待下载请求和有效本地资源，When 离线启动，Then 先使用本地资源，保留下载请求。
- Given 在线空闲，When 更新资源，Then 停止所有旧资源使用后写入，加载成功后才清除请求。
- Given 下载或加载失败，When 现有分区不再有效，Then 使用内置基础界面，保留 BOOT 操作，不使用失效模型。

## Constraints

只对 HOME Rev2.0 启用；BOOT 长按 3 秒、命令窗口 8 秒、前台连接 15 秒、重试间隔上限 300 秒；
音量 0–100、亮度 1–100，步长均为 10。八条固定说法及 AC01–AC24 原样继承已确认方案。
固件构建与主机测试不代替设备语音识别和硬件验收。
